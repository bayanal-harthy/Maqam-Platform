# مقام — نموذج موقع أكاديمي تفاعلي

«مقام» منصة رقمية سعودية **مقترحة** لخدمة شركات تنظيم حملات الحج المرخصة في البحث عن عمائر إسكان الحجاج بمكة المكرمة. المشروع من ملف Word المرفق للمجموعة الأولى — جامعة دار الحكمة، مقرر ريادة الأعمال.

## التشغيل والنشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثل `maqam-demo`).
2. ارفع محتويات المجلد إلى جذر الفرع `main`، خصوصًا `index.html`.
3. افتح **Settings → Pages → Build and deployment** واختر **Deploy from a branch** ثم `main` و`/(root)`، واحفظ.
4. سيصبح العرض متاحًا على رابط شبيه بـ `https://USERNAME.github.io/maqam-demo/` بعد اكتمال النشر.

كما يمكن فتح `index.html` مباشرة على الكمبيوتر دون تثبيت أو تجميع. يحتاج خط Cairo إلى الإنترنت، مع خطوط بديلة محلية.

## الصفحات والوظائف

- الرئيسية والبحث السريع.
- استكشاف 12 بطاقة **افتراضية** مع فلاتر الحي والسعة والفترة والترتيب.
- صفحة تفاصيل العمارة وحالة المستندات/المراجعة التوضيحية.
- المقارنة بين حتى 3 بطاقات.
- المفضلة والبحوث المحفوظة وطلبات المعاينة **التجريبية** في لوحة شركات الحملات.
- لوحة مالك لإضافة مسودات محلية لا تُنشر.
- صفحة الاشتراك المقترح 1200 ريال شهريًا وخطة المشروع، وصفحة تعريفية، وتواصل توضيحي.
- تصميم RTL متجاوب للجوال والتابلت والكمبيوتر، وقائمة جوال، ووضع داكن.

## حدود النسخة وخصوصية البيانات

جميع العمائر والأسماء والسعات والمسافات والأسعار وفترات التوافر صور وأرقام **افتراضية**، وليست قوائم عقارات حقيقية. لا توجد مصادقة مستخدمين، ولا مستندات رسمية، ولا قاعدة بيانات، ولا تأكيد توافر، ولا حجوزات أو مدفوعات فعلية. تحفظ المفضلة والمقارنة والطلبات والمسودات داخل `localStorage` في متصفح الزائر نفسه، ولا تتزامن بين الأجهزة أو المستخدمين. لا تستخدم الموقع لجمع بيانات حساسة.

قبل أي تشغيل تجاري يجب استيفاء التراخيص والامتثال والتحقق من تصاريح إسكان الحجاج وبيانات العمائر ومواءمة المتطلبات النظامية وإنشاء نظام خلفي آمن.

## الملفات

- `index.html`: تطبيق كامل دون أي مكتبات JS خارجية.
- `screenshots/`: لقطات النسخة البصرية المرجعية الواردة في ملف ZIP الأصلي.
- `.nojekyll`: لتعطيل معالجة Jekyll غير المطلوبة.

## اختبار سريع

افتح الموقع، جرّب البحث عن «العزيزية»، وأضف بطاقتين للمقارنة، ثم أنشئ طلب معاينة تجريبيًا وراجعه في لوحة الحملات. أعد تحميل الصفحة للتحقق من حفظه محليًا.
